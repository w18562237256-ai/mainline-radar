# A股主线雷达

用于监测A股阶段主线、板块轮动、资金强弱和龙头梯队。

线上地址：https://mainline-radar-cn.briefs-velvety-9h4b6.chatgpt.site/

## 当前版本：前向监测模型 V4

- 每30秒重新扫描免费行情源，而不是重复读取仓库静态文件
- 免费行情源中断时明确显示“历史复盘模式”，不冒充实时信号
- 电网设备 `BK0457` 被列入强制覆盖范围，避免因板块目录缺口漏检
- 成分关系使用 `constituentVerified`，题材关系使用 `themeRelationVerified`，两者不再混用
- 历史涨跌数据不一致时，持续性直接按0分处理
- 实时信号按首次发现时间写入D1，只追加、不覆盖
- 页面只输出“候选主线”，不输出买入结论

## 数据链路

`/api/market`会尝试执行前向扫描，并把结果写入信号账本。只有 `sourceMode=live_scan` 的记录参与未来命中率统计。

仓库中的 `public/market-data.json` 是2026年7月24日历史复盘，包含事后人工校正。它只在实时行情源不可用时作为降级展示，不属于预测记录，也不用于证明模型提前识别了长城军工。

当前仍然不能宣称模型有胜率。需要积累足够多的前向记录后，再按首次发现价格计算次日、3日、5日收益、最大回撤和失效时间。

## 本地运行

```bash
npm install
npm run dev
```

更新市场快照：

```bash
npm run market:update
```

构建与测试：

```bash
npm run lint
npm test
```

公开行情可能延迟或中断，内容仅供市场研究，不构成投资建议。
